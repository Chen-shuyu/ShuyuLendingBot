## 2026-09-05 —— 五天沒回來，而這五天正好是 D056 的第一組完整證據

**沒有改任何程式。** 這一段全部是查證：容器自 08-30 22:57 起 healthy、
日誌 0 ERROR、跑滿 5 天 4 個完整循環。四則決策 **D060／D061／D062／D063**
都是從這批資料讀出來的，沒有一項來自推論。

### 一、D056 有效，而且效果比預期大——但它的理由是錯的（D060）

| 項目 | D056 之前 | D056 之後（09-01～09-04 四整天） |
|---|---|---|
| **實得年化（帳本）** | 5.72% | **7.75%** |
| 換手空窗 | 3.6h／38.1h／24.7h | **0.68h／0.26h／0.13h** |
| 資金利用率 | 約 7 成 | **98.8%** |

**瓶頸換人了**：以前是「借不出去」，現在空窗接近 0，**唯一剩下的槓桿是價格**。
而 15% 手續費是常數（帳本淨 ÷ 推算毛 = **81.2%**，與 85% 一致），改不動。

**但 `assumed_hold_hours: 12` 被實測否定**：D056 後結清 3 筆，
**48.33h／48.19h 都借滿 2 天**、1 筆 1.43h；第 4 筆 `465110649` 已持有
39.3h 仍在生息。在 8.76～9.00% 這一帶，持有時間是 **48h，不是 12h**。

### 二、選中哪個價位，目前是由浮點雜訊決定的（D061）

拿正式 DB 的最新一窗跑 `expected_value.py` 本尊：

```
 8.7600%  實質=7.695058824   <== 選中
 8.9279%  實質=7.695017700   差 0.00004 個百分點
```

距最佳 1% 以內有 4 個候選，橫跨 8.74%～8.93%。而 `choose_rate()` 用
`effective > best_effective` ＋升冪掃描，**平手時系統性地選便宜的那一個**。
正式環境 09-04～09-05 在 8.76% 與 8.93% 之間來回跳，跳的就是這 4×10⁻⁵。

### 三、目標函數是自我矛盾的（D062）

同一窗、只改 `P`：

```
  掛價% |  P=12h  P=24h  P=48h  P=72h        P 假設 → 選中價
   8.76 |   7.69   8.19   8.47   8.56          12h → 8.76%
   8.93 |   7.69   8.26   8.58   8.70          24h → 8.93%
   9.40 |   6.96   8.00   8.64   8.88          48h → 9.40%
  10.22 |   4.32   6.11   7.70   8.44          72h → 10.22%
```

照實測把 `P` 設成 48h，策略就跳到 9.40%——**但 48h 是在 8.9% 觀察到的，
9.40% 的持有時間我們沒量過**。`rho(利率, 持有) = −0.383`（n=17，D058 的 −0.29 更新）。
**這不是「該填哪個數字」，是不動點問題。**

而 `--simulate` 現在不能當裁判：`empirical_hold()` 整包抽持有時間，
**等於給高價位配了一個它拿不到的持有時間**。

### 四、所有樣本都是模型自己選出來的（D063）

- 12 個等待校準樣本全部落在 **8.76～9.50%** 這條機器人自己選出來的窄帶；
  10% 以上只有 2 個意外樣本，而它們正好是 D058 的全部關鍵證據。
- `repost_comparisons` 從 0 列長到 **187 列**，但 **186 列是 `hold_matched`
  （候選＝場上同價）**，唯一 1 列 `repost` 是 D056 部署自己觸發的。
  **儀器在跑，資訊量是零。**

### 五、順帶查到的兩件小事

- `bot_engine.py:1166` 傳 `principal_avg=None`，所以 09-01 起 `earnings_daily`
  的本金全是 NULL，實得年化只能手打一個會漂的數字（344.31 → 345.29）。
- `expected_value.py` 那段「實測平均 16.93h／中位 11.61h」的註解已過期
  （現為 22.60h／11.62h）。

### PR #64 —— 而第 2 順位的答案是否定的（D062）

跨 114 個起跑點，兩個裁判並排：**都指向 `P=12`**。換裁判動 **0.065pp**，
換假設（12 對 48）動 **1.267pp**——**差 19.4 倍**。
而且**策略就算自己用 `P(r)` 也選同一個價位**（8.93%）。

🔴 **原因是結構性的**：選中的價位在分界線（年化 9.31%）**底下**，
**那一階從來沒有被跨過**。

**但「結案」是有條件的**：整段歷史只有 **2.8%** 的決策點跨過分界線（用現在的 `P=12`），
而正式環境 08-17 起真的掛出去的 16 張單有 **43.8%** 跨過（那時是 `P=48`）。

> **是 D056 把作業點壓到分界線底下，才讓 D062 的疑慮變成無關緊要的。**
> **D062 因此是 D063 的前置條件，不是一個可以獨立收掉的改動。**
