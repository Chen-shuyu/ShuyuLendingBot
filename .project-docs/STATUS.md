## 一句話

**機器人真金運作中，而且它終於賺錢了**——實得年化（帳本）**5.72% → 7.75%**、
資金利用率 **98.8%**。D056（`assumed_hold_hours: 12`）跑滿 5 天 4 個完整循環，
🟢 **有效（D060）**。09-05 一天合併兩個 PR：**#60 修掉量測的幽靈樣本（D057）**、
**#61 讓選價不再由浮點雜訊決定（D061，已上線，等下一次換手驗收）**。
但同一批資料同時說了三件事：
🔴 **它有效的理由是錯的**——`P=12` 被實測否定，8.76～9.00% 那一帶**借滿 48h**；
🔴 **選價現在是由浮點雜訊決定的（D061）**——前兩名差 4×10⁻⁵ pp，
而平手規則系統性偏向便宜那邊；
🔴 **目標函數自我矛盾（D062）**——用常數 `P` 最佳化 `r`，而 `P` 是 `r` 的函式，
**連回測裁判都一起被污染**；
🔴 **所有樣本都是模型自己選出來的（D063）**——量再久也不會有新資訊。

🔴 **瓶頸換人了**：問題不再是「借不出去」，是「賣太便宜」。空窗已接近 0，
**唯一剩下的槓桿是價格**（手續費 15% 是常數，改不動）。
